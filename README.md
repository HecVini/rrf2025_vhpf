# Shifting Landscapes: The Impact of Agricultural Innovation on Deforestation: Replication Package

## 1. About

This paper explores the impact of genetically modified (GM) soy on deforestation in the Amazon. GM soy substitutes extensive cattle ranching with more productive grazing systems, reducing deforestation. However, it can also displace pastures northward, indirectly increasing forest loss. In this study, both effects are quantified.

## 4. Code
### 4.1 How to Run
This project is intended to be replicated by running three files. 
First, open the `replication_package.Rproj` at the beginning of the folder. Then, run `master.R`, which will create the project's folders, set the renv, and do all the cleaning and analysis. Notice that this takes hours to run, as some parts of the cleaning are really data-intensive.
